# App Store Screenshot Guidelines

## Version: 1.0.1 (Build 13)
## Target: September 2026 Release

---

## 1. Technical Requirements

### iPhone Screenshots
- **Dimensions**: 1242 x 2688 pixels (iPhone 14 Pro / 6.1" display)
- **Format**: PNG or JPEG
- **Minimum**: 2 screenshots
- **Recommended**: 5 screenshots
- **Maximum**: 10 screenshots
- **Safe Area**: Leave 40px margins on sides

### iPad Screenshots
- **Dimensions**: 2048 x 2732 pixels (iPad Pro 12.9")
- **Format**: PNG or JPEG
- **Minimum**: 2 screenshots
- **Recommended**: 5 screenshots
- **Maximum**: 10 screenshots
- **Safe Area**: Leave 60px margins

### Text Overlay Requirements
- **Font**: San Francisco or system font
- **Caption Size**: 60-80pt bold
- **Description Size**: 40-50pt regular
- **Color**: White text with dark semi-transparent background for contrast
- **Position**: Bottom third of screen recommended
- **Padding**: 30-40px from edges

## 4. Design Guidelines

### Color Palette
- **Primary Color**: Brand Purple (#6C5CE7 or similar)
- **Secondary**: Accent Blue (#0984E3)
- **Success**: Green (#00B894)
- **Warning**: Orange (#FDCB6E)
- **Danger**: Red (#D63031)
- **Neutral**: Gray (#636E72)

### Typography
- **Headlines**: San Francisco Bold, 60-80pt
- **Body Text**: San Francisco Regular, 40-50pt
- **Captions**: San Francisco Regular, 32-40pt

### Layout
- Material Design 3 principles
- 40px side margins on iPhone, 60px on iPad
- Card-based UI with rounded corners (16-20px radius)
- Smooth transitions and animations
- Consistent spacing (8px base unit)

### Content Tone
- **Japanese First**: All captions in Japanese with English as secondary
- **Empowering**: Language about participation, impact, understanding
- **Clear**: Simple, direct messaging
- **Inclusive**: Show diverse user types participating

### Dark Mode
- All screenshots should work in both light and dark modes
- Test on both iPhone and iPad
- Ensure text contrast meets WCAG AA (4.5:1 minimum)
- Use system dark mode colors

## 5. Screenshot Creation Process

### Step 1: Prepare Device/Simulator
```bash
# Ensure simulator is running iOS 15.0+
# Use iPhone 14 Pro (1242x2688) for primary screenshots
# Use iPad Pro 12.9" (2048x2732) for tablet shots
```

### Step 2: Set Up Screenshots
1. Enable simulator zoom for better visibility
2. Remove status bar apps (clock, battery) if possible
3. Use consistent time (10:09 AM is standard)
4. Ensure reproducible app state for each screenshot

### Step 3: Capture & Export
1. Use Xcode's Screenshot tool or Simulator screenshot
2. Export at full resolution (1242x2688 for iPhone)
3. Verify file format is PNG or JPEG
4. Name consistently (01_onboarding.png, 02_voting.png, etc.)

### Step 4: Add Captions
- Use screenshot editing tool (Keynote, Figma, or similar)
- Add text overlay with semi-transparent background
- Position caption in bottom 1/3 of screen
- Japanese text on top, English below (optional)
- Ensure minimum 4.5:1 contrast ratio

### Step 5: Finalize
1. Verify dimensions exactly match requirements
2. Test both light and dark mode versions
3. Check text is readable and centered properly
4. Export final PNG files
5. Verify file sizes are reasonable (500KB-2MB each)

## 6. Common Mistakes to Avoid

❌ **Don't**:
- Use placeholder text or Lorem Ipsum
- Show development/debug UI elements
- Use small fonts that aren't readable
- Overlap important app content with captions
- Use screenshots of old app versions
- Inconsistent styling across screenshots
- Poor color contrast (will fail accessibility)
- Real user data or identifiable information
- Beta/test build indicators
- Untranslated text

✅ **Do**:
- Use realistic, representative app state
- Highlight key features clearly
- Test on actual device if possible
- Use professional typography
- Maintain consistent visual style
- Follow Material Design 3 guidelines
- Test contrast ratios
- Use appropriate Japanese terminology
- Show production build UI
- Get approval before uploading to App Store Connect

## 8. Testing Before Submission

### Verification Checklist
- [ ] All screenshots are correct dimensions (1242x2688 iPhone, 2048x2732 iPad)
- [ ] All screenshots are PNG or JPEG format
- [ ] File sizes are within reasonable range (< 3MB each)
- [ ] Captions are readable and accurately describe app
- [ ] Text color contrasts properly against background
- [ ] No debug UI, watermarks, or development artifacts visible
- [ ] Consistent styling across all screenshots
- [ ] Japanese text is correct and properly formatted
- [ ] Both light and dark mode versions prepared (if applicable)
- [ ] Screenshots match current app version (1.0.1)
- [ ] No real user data or identifiable information visible
- [ ] All 5 iPhone + 5 iPad screenshots prepared
- [ ] Screenshots follow Material Design 3 principles

### App Store Connect Preview
- Upload all files to App Store Connect
- Preview on different devices before submission
- Verify they appear correctly on App Store product page
- Test that captions are readable in preview
- Confirm no quality issues or artifacts visible
